# Universal Frame wordmark

`public/brand/universal-frame-wordmark.webp` is the final transparent image used beside the existing frame icon in the header. The bitmap was generated with the built-in image-generation tool, inspected for exact spelling, and converted losslessly to WebP for delivery. The singular business name follows the requested branding. The original frame icon is unchanged.

Prompt:

> Create one transparent horizontal wordmark reading “UNIVERSAL FRAME” in uppercase, exactly U-N-I-V-E-R-S-A-L then F-R-A-M-E. Sophisticated architectural/building-company typography: strong clean geometric sans-serif, restrained angled frame-like cuts, medium-bold to bold slightly condensed letterforms, optically balanced spacing and readable at 230 pixels wide desktop and 185 pixels mobile. UNIVERSAL in forest green #206443 and FRAME in rich yellow #e8ba36. Only these two words. No icon, slogan, backdrop, outer frame, extra letters, gradients, shadows, bevel, 3D, perspective, mockup, texture or watermark. Genuine transparent alpha; one wordmark, no variants or contact sheet.

Original dimensions: 2172 × 724 pixels. CSS crops the transparent padding in its masthead box; the asset itself is not geometrically altered. No social preview image was generated or replaced.
